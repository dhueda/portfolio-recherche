# Veille médiatique et analyse de discours

Six notes de synthèse sur le secteur des télécoms (2024-2025), issues de mon travail de chargée d'études média dans un bureau d'études conseil. Deux notes portent sur l'organisation du travail et le climat social.

## Question
Comment la presse traite-t-elle un événement ? Quels médias s'en saisissent, sur quelles sources ils s'appuient, quel récit ils construisent.

## Méthode
Veille quotidienne d'environ 40 sources, sélection et codification dans un corpus structuré, analyse qualitative des discours des acteurs (journalistes, dirigeants, syndicats, experts).
